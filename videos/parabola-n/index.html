הפרבולה y = n·x²

הזיזו את n וראו: כל גובה על הגרף מוכפל ב־n.

מה רואים כאן?

הקו האפור הוא y = x². הקו הכחול הוא y = n·x². הקווים הצהובים הם הגבהים ב־x = ±1 וב־x = ±1.5.

לכל x, הגובה של הכחול הוא בדיוק n כפול הגובה של האפור. לכן:

  • n > 1 — הגבהים גדלים: הפרבולה צרה יותר.
  • 0 < n < 1 — הגבהים קטנים: הפרבולה רחבה יותר.
  • n = 0 — כל הגבהים מתאפסים: קו ישר y = 0.
  • n < 0 — הגבהים מתהפכים: הפרבולה פתוחה כלפי מטה.
x = 1 ⟹ y = n

הנקודה הירוקה (1, n) מראה את n ישר על הגרף. בסרטון רואים את המתיחה, הכיווץ וההיפוך צעד אחר צעד.
