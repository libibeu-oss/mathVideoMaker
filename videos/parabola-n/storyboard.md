# סטוריבורד: הפרבולה y = n·x² — מה עושה n?

## מידע בסיסי
- **הרעיון בשורה אחת**: n מכפיל כל גובה על הגרף — לכן הוא מותח, מכווץ, משטיח או הופך את הפרבולה.
- **מטרת הלמידה**: התלמיד יודע לנבא את צורת הגרף לפי n, ולקרוא את n מהנקודה (1, n).
- **קהל**: חטיבה / תיכון.
- **תוצרים**: סרטון (`ParabolaN.mp4`, כ־68 שניות) + דף אינטראקטיבי (`index.html`).

## מפרט עיצוב משותף (סרטון + דף)
- **סימונים**: y = n·x²; בסיס y = x² באפור; גבהים בצהוב ב־x = ±1, ±1.5; נקודה ירוקה (1, n).
- **פרמטרים**:
  | פרמטר | משמעות | טווח בדף | צעד | ערכים בסרטון |
  |------|--------|---------|-----|-------------|
  | n | מקדם x² | −3 עד 3 | 0.1 | 1 → 2 → 0.5 → 0 → −1 → 1 |
- **צירים**: x מ־−3 עד 3, y מ־−3 עד 5.
- **צבעים**: רקע `#0f1419`, עקומה `#5b9cff`, בסיס `#46505f`, גבהים `#ffd166`, נקודה `#5ed68c`.

## קו ההסבר (יותר ממחצית הסרטון)
1. ב־y = x² הגובה בכל x הוא x² ← מסמנים גבהים כעמודות.
2. כופלים ב־n ← כל עמודה מוכפלת ב־n, והעקומה עוברת דרך קצות העמודות.
3. n = 2 ← גבהים כפולים ← צרה יותר; ב־x = 1 הגובה הוא n.
4. n = 0.5 ← גבהים בחצי ← רחבה יותר.
5. n = 0 ← כל הגבהים 0 ← קו ישר.
6. n = −1 ← גבהים שליליים ← הפוכה.
